# Tuxery `catalog` docs

Reference docs for this repo, one topic per file — not a tutorial, not a
changelog. If it explains _why_ the data pipeline is shaped the way it is,
or tracks a decision that isn't obvious from the code, it belongs here
rather than as a comment scattered across packages.

- [`sources.md`](sources.md) — every upstream source Tuxery could pull
  from, whether it's implemented yet, and how.

Roadmap and task tracking stay on the
[Tuxery GitHub Project](https://github.com/orgs/tuxery/projects/1), not
here — see the root `AGENTS.md`'s "Rules" section.
